Design approach

I treat a website as an information system before treating it as decoration. The first task is to clarify what the visitor needs to understand, which action matters, and how the content should be grouped. Visual direction is then used to reinforce that hierarchy.

Selected experiences

  • Hihie’s Scent OS — a data-backed personal product with weather and discovery modes.
  • Interactive Reports — dense research and sales data translated into filters, charts and insights.
  • Saigon Root Music — an atmospheric creative website concept for an audio mastering studio.
  • Mautic Showcase — a visual explanation of a lifecycle automation system.

Implementation priorities

Responsive layout, readable typography, useful interaction, semantic HTML, descriptive metadata and resilient internal links are treated as core requirements. The upgraded portfolio also separates public case studies from operational pages that should not be indexed.

Connected portfolio system

The current site is organized around a central project directory, articles, an about profile, a CV and contact page. Each indexable page has a canonical URL, social preview metadata, structured data and a path back into the wider portfolio.
