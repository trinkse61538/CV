# KhaiTriOS Private Vault

This repository is the protected source of truth for Nguyen Khai Tri's personal operating context.

## Purpose

The vault gives AI assistants and future workflows a stable understanding of:

- professional identity and active direction;
- working preferences and quality expectations;
- decision principles and delivery standards;
- current projects and operating context;
- publishing boundaries between public and private knowledge.
