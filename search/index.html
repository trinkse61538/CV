How it works

Tìm kiếm nhanh mà không cần server hoặc API.

The system uses weighted metadata, bilingual synonyms and indexed page content to rank results directly in the browser.

Weighted relevance

Titles, topics, keywords and page content receive different weights so results are not ranked by raw word count.

Bilingual synonyms

English and Vietnamese terms are connected, including tracking/đo lường, fragrance/nước hoa and automation/tự động hóa.

Static and private

Search runs in your browser from a small JSON index. No query is sent to a server or third-party API.
